Select the appropriate ROM file based on the virtual machine's architecture: use EFI32 for 32-bit or EFI64 for 64-bit. Place the ROM file into the virtual machine's folder. Once done, use Notepad to append the following line to the end of the virtual machine's .vmx file:

efi32.filename = "EFI32-MACOS.ROM" (for 32-bit)
efi64.filename = "EFI64-MACOS.ROM" (for 64-bit)
